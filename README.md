# HelloWorld iOS App

A simple iOS app that displays "Hello, World!" on the screen.

## Requirements
- Xcode 14.0 or later
- iOS 16.0 or later
- macOS Ventura or later

## How to Run
1. Open Xcode
2. Open the project by selecting `HelloWorld.xcodeproj`
3. Select an iOS simulator or connected device
4. Click the Run button (▶️) or press `Cmd + R`

## Project Structure
- `HelloWorldApp.swift`: Main app entry point
- `ContentView.swift`: Main view containing the "Hello, World!" text
- `Project.swift`: Project configuration file

## Development
This project uses SwiftUI for the user interface. The app is built with a simple structure:
- `HelloWorldApp`: The main app structure
- `ContentView`: The main view that displays "Hello, World!"
